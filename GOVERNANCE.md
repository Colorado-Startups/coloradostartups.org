# Governance

Colorado Startups owns the project. The maintainers ([`MAINTAINERS.md`](MAINTAINERS.md)) run it day to day.

| Decision | Who decides |
| --- | --- |
| An idea becomes an issue | A maintainer, in Discussions |
| An AI-mergeable PR merges | An AI agent, after the required checks and both AI reviews pass ([`CONTRIBUTING.md`](CONTRIBUTING.md)) |
| Any other PR | The orchestrator rebuilds it with the contributor as co-author, until a maintainer holds the seat ([`CONTRIBUTING.md`](CONTRIBUTING.md)) |
| The merge policy, the gates, these rules | Paul |
| The license: CC0 1.0, and code also 0BSD ([`README.md`](README.md#license)) | Paul. A change applies only to work after it; CC0 cannot be taken back |

## The Website maintainer seat

**The rule (Paul's to change; open item on #552):** a contributor with five merged pull requests over three months may ask for the seat. Paul says yes or no.

| Question | Default until Paul decides |
| --- | --- |
| What first | Five merged PRs over three months, and the Code of Conduct kept |
| Who decides | Paul |
| What the seat can do | Approve and merge PRs that wait for a maintainer; turn ideas into issues; welcome new contributors |
| What stays Paul's | The merge policy, the gates, secrets, deploy settings and production |
| How it ends | Stepping down at any time, or six months with no review; Paul can end it |

Every seat is filled by a person. AI agents never hold one.
