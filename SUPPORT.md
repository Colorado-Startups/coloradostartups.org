| Need | Where |
|---|---|
| Report a bug | [Issues](https://github.com/Colorado-Startups/coloradostartups.org/issues/new/choose), the **Bug** form |
| Propose an idea or a feature | [Discussions: Ideas](https://github.com/Colorado-Startups/coloradostartups.org/discussions/categories/ideas) |
| Ask a question | [Discussions: Q&A](https://github.com/Colorado-Startups/coloradostartups.org/discussions/categories/q-a) |
| Report a security problem | [SECURITY.md](SECURITY.md), never a public issue |
| Report conduct | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Contribute a change | [CONTRIBUTING.md](CONTRIBUTING.md) |
| See the scores and process maps | [Quality](https://colorado-startups.github.io/coloradostartups.org/), [Process](https://colorado-startups.github.io/coloradostartups.org/process.html) |
